Types of Lists

Ordered List

An ordered list uses numbers:

<ol>
  1. First item
  2. Second item
  3. Third item
</ol>

Unordered List

An unordered list uses bullet points:

<ul>
  • Apple
  • Banana
  • Cherry
</ul>
