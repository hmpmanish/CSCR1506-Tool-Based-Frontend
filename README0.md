# CSCR1506 – Tool Based Frontend

## Experiment: Basic HTML Page Using Different Tags

---

## 📌 Aim
To design a simple web page using HTML5 and demonstrate the use of:
- Basic HTML structure
- Text formatting tags
- Images and links
- Lists
- Forms and input elements

---

## 🧠 Introduction
HTML (HyperText Markup Language) is used to create the structure of web pages.  
It uses tags to display text, images, links, lists, and forms on a web browser.

---

## 🧱 Basic Structure of HTML

```html
<!DOCTYPE html>
<html>
<head>
<title>My Website</title>
</head>
<body>
</body>
</html>

Explanation:

<!DOCTYPE html> → Declares HTML5 document

<html> → Root element

<head> → Metadata section

<title> → Browser tab title

<body> → Visible content of the page
